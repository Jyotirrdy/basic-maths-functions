# basic-maths-functions

A simple Python project containing common basic maths functions.

## Features

- Arithmetic: add, subtract, multiply, divide, modulus
- Power helpers: power, square, cube, root
- Utilities: absolute, average, percentage
- Number helpers: factorial, is_even, is_odd

## Quick start

```bash
python -m pip install pytest
pytest -q
```

## Example

```python
import maths_functions as mf

print(mf.add(10, 5))         # 15
print(mf.divide(20, 4))      # 5.0
print(mf.factorial(6))       # 720
print(mf.percentage(40, 80)) # 50.0
```
